Multi-Coin AI Trading Bot

A Python-based cryptocurrency market monitoring, paper trading, and backtesting project.

Project Overview

This project is designed to monitor multiple cryptocurrency markets, analyze trading signals, and evaluate trading strategies using historical market data.

The main goal is to develop and test systematic trading strategies while prioritizing risk management and capital protection.

Supported Trading Pairs

* BTC/USDT
* ETH/USDT
* SOL/USDT
* BNB/USDT
* XRP/USDT
* DOGE/USDT
* LINK/USDT
* AVAX/USDT
* ADA/USDT

Technologies

* Python 3.13
* CCXT
* Pandas
* Binance USDⓈ-M market data
* CSV data analysis
* HTML, CSS and JavaScript

Main Features

* Multi-coin market monitoring
* Historical market data analysis
* Backtesting of trading strategies
* Paper trading (virtual trading)
* Stop-loss and take-profit logic
* Position sizing and risk management
* Trading performance reports
* CSV-based trade history

Backtesting

The project includes historical strategy testing with:

* Entry and exit simulations
* Stop-loss and take-profit checks
* Trading fee estimates
* Risk-based position sizing
* Profit and loss calculations
* Maximum drawdown analysis
* Profit factor calculations

Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Install dependencies:

pip install ccxt pandas

Run the main program:

python main.py
